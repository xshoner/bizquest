# 메인페이지 디자인 DNA: Serious Play

비즈니스 교육의 신뢰감을 바탕으로, 팀 활동과 의사결정의 재미를 절제해 표현한다.

- 바탕: `#F7F8FA`, 텍스트: `#0B1220`, 주요 색상: `#1D2B64` / `#0F172A`, 성장 포인트: `#10B981`.
- 기존 Q·로켓 로고, Pretendard/SUIT, 성과 통계를 유지한다.
- 제목 700~800, 본문 500~600. 대비는 글자 크기·색상·여백으로 만든다.
- 버튼 10~12px, 카드 14~16px 모서리. 얇은 테두리를 기본으로 하고 그림자는 진입 카드에 미세하게 사용한다.
- 배경 다중 그라데이션과 장식용 히어로·과정 일러스트는 사용하지 않는다.
- 첫 화면은 핵심 메시지와 지표, 교사·학생 진입 카드의 두 열이다. 모바일은 한 열로 전환한다.
- 기능 소개는 아이콘 카드, 교육 가치는 번호가 붙은 목록, 수업 과정은 8단계 순서도, 활용 사례는 상단 선과 인용문으로 구분한다.
- 작동하지 않는 과정 버튼을 순서 목록으로 바꾼다. 진입 폼은 Enter 제출, 탭은 방향키 탐색, FAQ는 기본 details/summary를 사용한다.

## 스타일 소유권

모든 `.landing-*` 스타일은 `src/landing.css`에서 관리한다. `src/styles.css`에는 랜딩 스타일을 추가하지 않는다. 기본 규칙을 한 번 정의하고 반응형·상태별 규칙만 구분한다. 색상 변수는 `.landing-page`에 한정해 게임방 화면에 영향을 주지 않는다.

문구 기본값은 `src/lib/appSettings.js`에서 관리한다. `landingCopy.js`는 저장된 이전 기본 문구만 새 문구로 전환하며 관리자 맞춤 문구와 통계는 보존한다.
